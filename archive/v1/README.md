# Version 1 benchmark archive

This directory preserves the original local library, generator, experimental benchmark subjects, and README supplied in the workspace (project version `1.1.0-beta.7`). Git metadata was absent when the snapshot was taken. These local sources differ from upstream commit `94f205f5258a21a8316fb6b3c2829a9a56c74692`, from which repository history was subsequently restored. This is a local-source baseline, not a claim to reproduce a published NuGet binary or that upstream commit. Library C# sources are unchanged; [SHA-256 checksums](SOURCE-SHA256.txt) identify the exact snapshot.

The archived library project alone is adapted for comparative measurement: it targets .NET 6 and .NET 10, optionally .NET 11 with `-p:EnableNet11=true`; has assembly name `Tedd.SpanUtils.Archive.V1`; and disables packaging and obsolete development analyzers. The original project is retained as `Tedd.SpanUtils.csproj.original`. Modern SDKs define `NETCOREAPP`, selecting the original optimized .NET branch. Recompiling both source versions for each measured runtime keeps JIT/runtime improvements separate from library changes.

The active benchmark project references this library through `extern alias archive`. It does not rewrite namespaces or copy selected implementations. Each benchmark compares the same workload and validates compatible results in `GlobalSetup` before timing. The original generator and experimental benchmark project are historical references and are excluded from the active solution.

Version 1 contains known correctness defects. It is a measurement baseline, not a supported distribution; benchmark comparisons cover valid inputs with equivalent behavior. See [benchmark methodology and results](../../docs/benchmarks/README.md).

## Compile compatibility patch

The original local snapshot did not compile: 12 generated decimal readers return undefined `a[0]`, and four generated byte-array readers return a `bool`. The project deterministically creates `obj/.../SpanUtils.compat.generated.cs`: the decimal return is changed to the already-read local `r`, and the four unusable byte-array methods throw `NotSupportedException`. Neither family is measured. The transformation asserts the expected replacement counts, and the original tracked C# source remains byte-for-byte intact. This patch only makes the unaffected benchmark subjects executable.
