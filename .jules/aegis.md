## 2026-09-29 - SpanMoveWrite and SpanRead Coverage Expansion

Operations involved `MoveWriteVInt` and `ReadVInt` methods across `Span<byte>` and `ReadOnlySpan<byte>` types. VInt logic enforces a maximum representative value based on its byte-length constraints.
**Strategic Action:** Developed comprehensive parameterized unit tests leveraging `[Theory]` and `[InlineData]` constructs in `SpanMoveWriteTests.cs` and `SpanReadTests.cs`. Evaluated explicit boundaries including 1-byte, 2-byte, and multi-byte markers. Tested bounds, buffer underflow handling with `Try` methods, exception assertion for unreadable blocks (`InvalidDataException`), and restricted max-length scenarios. This process yielded an increase to 100% full method branch coverage for both sub-systems. Used specific try-catch implementations internally when ref structs like `Span` couldn't map inside lambda delegates in xUnit.
