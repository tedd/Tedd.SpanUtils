Purpose-built binary primitives

Control the representation and the storage.

The API separates buffer ownership from binary representation. Operations validate capacity, preserve cursor state on failed Try calls, and expose explicit little-endian and big-endian forms for portable formats.

Explicit cursor semantics

Advance only after success.

Move operations consume a span by reference. Their Try variants do not advance the cursor or modify the destination when the complete value is unavailable.

  • Fixed capacityWrites cannot extend the supplied storage.
  • Logical lengthStream reads stop at written content, not buffer capacity.
  • Validated formatsReaders reject truncated and overflowing variable-width encodings.
  • Caller ownershipDisposal never disposes the backing memory.
CURSOR EXAMPLEPosition is encoded in the span

Span<byte> output = storage;

output.MoveWriteLE(123);
output.MoveWriteVLQ(300UL);

ReadOnlySpan<byte> input =
    storage[..(storage.Length - output.Length)];

ulong second = input.MoveReadVLQUInt64();
